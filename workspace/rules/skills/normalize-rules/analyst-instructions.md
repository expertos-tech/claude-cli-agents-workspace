# Analyst: instructions

Brief of one of the four analysts of `/normalize-rules`; read `analyst-common.md` first.

## Question

Which instructions does the older workspace give the model? Any instruction file of any assistant or editor, rule,
convention, prompt or prompt template, request template, process document, and the lessons it recorded. For each:
what it asks, whether it is still in use (referenced, recent in its history, or contradicted by later text), and
how it compares with the current `AGENTS.md`, `rules/*.md` and `custom/my-rules/`.

- A rule that repeats the core with values of its own (limits of one machine, a team's conventions): the values are
  the candidate, as an own rule that complements the core one, never a copy of it.
- A process rule (records of every request, session roles, queues, locks): check whether the current flow already
  gives that result; the steps themselves are rarely worth keeping.
- Lessons: only the general ones a session would repeat; the ones about one project belong to that project.
