# maintainers

[English](../../../maintainers/README.md) · Português (Brasil) · [Español](../../es/maintainers/README.md)

O trabalho de quem mantém o produto, às claras. Nada aqui é copiado para um workspace instalado, e nada aqui nomeia uma
empresa, um cliente ou uma pessoa: a evidência privada do uso real fica no `tmp/`, ignorado pelo git. O processo que
escreve estes arquivos está no `CLAUDE.md` da raiz e em `.claude/rules/process.md`.

| Pasta | O que guarda |
| --- | --- |
| `backlog/` | Ideias, defeitos, melhorias e débitos do produto que ainda não viraram pedido; um item por arquivo |
| `plans/` | Desenhos: o problema, as opções, uma recomendação e as decisões numeradas para o dono |
| `requests/` | Pedidos funcionais prontos para rodar com `/caw-prompt`: objetivo, BR-n, AC-n, fora de escopo, etapas com effort |
| `reviews/` | Relatórios de revisões independentes (por exemplo, uma revisão final antes de uma release); criada pela primeira |
